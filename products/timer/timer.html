Timer for Live Productions

A simple fullscreen timer designed for live productions, conferences, events, recordings and streaming.

Features:
• Count Up and Count Down modes
• Play and Reset buttons
• Keyboard shortcuts
• Adjustable timer size
• Custom red warning threshold
• Optional flashing alarm when the timer reaches zero
• Fullscreen support
• Auto-hiding control menu

Keyboard shortcuts:
SPACE — Start / Stop
ENTER — Reset
F — Full Screen
↑ / ↓ — Add / subtract one minute
← / → — Add / subtract one second
+ / - — Change timer size
