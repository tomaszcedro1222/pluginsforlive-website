How it works

Make room for the audio that matters

Choose which source should trigger ducking and which source should be lowered. Ducking Audio manages the level change and restores the mix when the trigger is no longer active.

Choose the audio sources

Define the source that should take priority and the sources that should be reduced.

Set the response

Adjust thresholds, hold time and fade behaviour for the production.

Run the live mix

The application lowers and restores the selected audio automatically as activity changes.

Key benefits

Consistent level changes without constant fader moves

Automatic attenuation

Lower background or programme audio when a priority source becomes active.

Adjustable timing

Tune the threshold, hold and transition times to match the pace of your event.

Selected vMix sources

Apply ducking to the inputs and audio channels relevant to your workflow.

Useful for

  • Simultaneous interpretation
  • Voice-over during videos or presentations
  • Conferences and hybrid events
  • Podcasts with music or playback sources

Designed for live control

Ducking Audio was created for situations in which one signal should temporarily reduce another. Adjustable timing helps the transition sound deliberate instead of abrupt.

Questions

Ducking Audio FAQ

What is audio ducking?

Audio ducking temporarily lowers one audio source when another, higher-priority source becomes active.

What can I adjust?

The application provides controls for trigger thresholds, hold time and fade times.

What workflows is it intended for?

Typical uses include interpretation, voice-over, podcasts, conferences and live events.

Is Plugins For Live affiliated with vMix?

No. Plugins For Live develops independent tools for vMix workflows.
